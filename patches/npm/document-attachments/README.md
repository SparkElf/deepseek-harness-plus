# @sparkelf/dsh-patch-document-attachments

English | [中文](README.zh.md)

This data-only package adds the generic official-source integration points required by `@sparkelf/dsh-plugin-document-attachments`: immutable generic objects in AttachmentStore, durable DocumentBlock content, request-only LLM projection from a persisted modelText artifact, prepared Session prompt callbacks, one mixed Client draft transaction, Host-projected Document limits, Session-authorized generic attachment reads, and nested composer, Chat, and Trajectory presentation slots carrying the preview content address. Image-only AttachmentStore providers retain an explicit generic-file unsupported result; the local provider overrides the complete generic object implementation. The payload also gives the existing attachment plugin one generic mixed image-and-document file chooser, registered in a dedicated composer slot rendered directly after the command button with a conversation-owned bilingual label. It contains no parser, wire admission, product delimiters, Document cards, provider endpoint, or fallback behavior; those remain in the capability package.

The target is exact official source revision `0a53fb55bea101816fa226bb964ae2bed71c343b`. The payload is applied before building that source tree. The package has no JavaScript entry, lifecycle script, Cordis plugin, compatibility adapter, or alternate variant.

Retire this package when official DSH supplies equivalent generic file-object storage, Document content persistence and model projection, prepared prompt settlement, mixed draft attachment integration, generic attachment file selection, authorized generic reads, and nested Document presentation slots.
