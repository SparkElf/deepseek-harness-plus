# 盘点与基线

## 查什么

- 资源：数量、类型、表/视图、`aiVisible`、`accessLevel`、描述为空。
- 列：数量、类型、空描述、无中文名、枚举/日期/金额列。
- 指标：数量、重复、表达式为空、同名冲突。
- 血缘：断点、视图→基表、指标依赖。
- 使用：高频查询列、从未查询的列（能取到查询日志时）。

## 工具

- 平台元数据：`query_table` 查 `resources`、`resource_columns`、`metrics`、`resource_lineages`。
- 样本：对重点表做 `SELECT ... LIMIT 20`，只看分布，不拉全量。
- 盘点结果写 `inventory.json`，作为本轮基线。

## 基线指标

- 列描述覆盖率
- 列中文名覆盖率
- 指标覆盖率/重复率
- 血缘完整率
- 问数准确率/延迟（如果已有 benchmark 结果）
