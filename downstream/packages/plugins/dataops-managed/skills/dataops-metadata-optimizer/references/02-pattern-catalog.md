# 规律目录

按优先级发现：

1. **枚举/状态**：低基数、重复值多的列 → 补枚举含义、字典绑定。
2. **日期/时间**：`date`/`timestamp`/`month` → 补时间口径、截止日、财年。
3. **金额/数量**：`amount`/`price`/`qty` → 补单位、币种、是否含税。
4. **ID/主键**：`*_id` → 补业务含义、是否唯一、join 对象。
5. **地域**：城市/区县/路段/服务区 → 补层级关系。
6. **join key**：同名/同类型列、view 定义 → 补血缘/关系。
7. **重复指标**：同一 sqlFragment/口径 → 合并。
8. **命名不一致**：同一概念多种叫法 → 统一。
9. **空描述/无中文名**：优先事实表、指标依赖列、高频过滤列。
10. **未使用列**：长期无查询 → 标记，不急着删。

每条规律必须带：证据（样本值/分布/查询/血缘）、置信度、影响对象。
